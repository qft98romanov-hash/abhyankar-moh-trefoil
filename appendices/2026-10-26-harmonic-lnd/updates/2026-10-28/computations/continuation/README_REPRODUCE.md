# Как воспроизвести точные проверки

26 октября 2026 года. Материалы находятся на стадии проверки. Файл `run_checks.py` запускает итоговые проверяющие программы и сохраняет протокол `aggregate_checks.json`. Он не запускает трудоёмкий поиск струевых решений и исходный поисковый перебор смешанной проекции.

## Быстрый запуск

Проверенная среда: Python 3.12.14, SymPy 1.14.0. Программы используют точную целочисленную и рациональную арифметику, без численных допусков. Другие версии Python/SymPy могут работать, но здесь не объявляются проверенными.

Для полной проверки нужна установленная SymPy. Например, в каталоге с этим файлом можно создать отдельное окружение:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install sympy==1.14.0
.venv/bin/python run_checks.py
```

В Windows вместо `.venv/bin/python` используется `.venv\Scripts\python.exe`. Если SymPy уже установлена в выбранном Python, достаточно:

```sh
python run_checks.py
```

Запускать можно из любого каталога, указав путь к `run_checks.py`. Драйвер сам устанавливает рабочий каталог каждого процесса равным каталогу соответствующего проверяющего файла. Не перемещайте отдельные проверяющие файлы без соседних сертификатов: некоторые независимые аудиты читают JSON из соседнего подраздела.

Не используйте `python -O` или `python -OO`: проверки содержат `assert`. Драйвер отвергает такой запуск, удаляет `PYTHONOPTIMIZE` у дочерних процессов и запускает их с отключённой записью байткода. Код сторонних зависимостей, виртуальные окружения и `__pycache__` не являются частью пакета.

## Проверки без сторонних зависимостей

Три программы в `embedding_lnd` используют только стандартную библиотеку Python:

```sh
python run_checks.py --stdlib-only
```

Это проверяет все 14 пар нижних/верхних струевых сертификатов, восемь нормальных реперов и сертификат единственности кубического полинома параметра H(4,5,7) вместе с 14 выбранными верхними срезами. Результат такой команды имеет область `selected_verifiers_only`; он не выдаётся за запуск остальных программ.

Отдельные проверки можно выбирать по идентификаторам:

```sh
python run_checks.py --only jet h457_multiplicity
python run_checks.py --only h457_degree4 h457_independent
```

При необходимости можно использовать существующий внешний каталог зависимостей, не копируя его в пакет:

```sh
python run_checks.py --sympy-path /absolute/path/to/python_packages
```

На каждую программу по умолчанию отводится до 600 секунд. Изменить предел можно аргументом `--timeout 1200`. Драйвер продолжает остальные проверки после ошибки и возвращает ненулевой код, если хотя бы одна выбранная программа завершилась неуспешно или по тайм-ауту.

## Что именно считается проверкой

Полный запуск содержит **14 программ**. Это число успешных запусков, а не число независимых теорем. Внутренние проверки имеют разные единицы, частично повторяют друг друга и намеренно не складываются в общий рекламный счётчик.

| ID | Файл и рабочий каталог | Смысл количества |
|---|---|---|
| `jet` | `embedding_lnd/verify_jet_certificates.py` | 14 пар сертификатов: восемь моделей при μ=1 и шесть дополнительных μ для H378. Каждая пара включает точный функционал нижней границы и явный верхний срез. |
| `formal_frames` | `embedding_lnd/verify_formal_frames.py` | Восемь нормальных реперов; проверяются градиент, ортогональность и определитель 1. |
| `h457_multiplicity` | `embedding_lnd/verify_h457_multiplicity.py` | Один определитель 20×20 и 14 выбранных верхних срезов: μ=1,…,12,25,100. Формула для всех μ требует приведённого доказательства. |
| `h378_linear` | `h378/verify_linear_coordinate_obstruction.py` | 13 именованных алгебраических тождеств и дополнительные значения для проверки знаков. |
| `h378_uniform` | `h378/verify_uniform_obstructions.py` | 20 индексов семейства, 160 полиномиальных проверок. Универсальный результат опирается на текст доказательства. |
| `h457_degree4` | `h457/verify_degree4.py` | 35 именованных точных утверждений одного доказательства обструкции степени ≤4. |
| `h457_independent` | `relative_ml/review_457_checks.py` | Независимые миноры, исключение параметров, результант и тождество Безу; часть содержания повторно проверяет предыдущий результат. |
| `jet_independent` | `relative_ml/review_jet_checks.py` | 27 явно раскрытых срезов и один минор единственности; независимая реализация через SymPy. |
| `relative_ml` | `relative_ml/verify_relative_ml.py` | 54 сдвига: шесть троек × три оси × три степени коэффициента. Общая теорема о всех идеалах доказана отдельно. |

| `image_ideal_audit` | `literature/verify_image_ideal_audit.py` | 28 выбранных явных прообразов. Эти проверки сами по себе не доказывают универсальную формулу идеалов образов. |
| `iterated` | `iterated_modifications/verify_iterated_filtration.py` | Три длины модификаций; для каждой порядки n=0,…,16 и дополнительные тождества. |
| `iterated_independent` | `h378/verify_iterated_review.py` | Пять длин; для каждой 65 двоичных тождеств, 81 тождество произведений и отдельные проверки базиса Грёбнера. |
| `mixed_projection_audit` | `h457/review_h378_checks.py` | 56 пар ограниченных кратностей e,f при 4≤e+f≤10, плюс исключительные параметры. Это конечный аудит, а не исключение всех неограниченных кратностей. |

Рабочий каталог каждой строки — папка перед именем `.py`. Для ручного запуска, например:

```sh
cd embedding_lnd
python -B verify_jet_certificates.py
```

Или укажите полный путь к проверяющему файлу: программы находят свои JSON по расположению собственного файла.

## Результаты запуска и ограничения

`aggregate_checks.json` содержит версии Python/SymPy, время, код завершения каждой программы, её SHA-256, область запуска и ссылки на `logs/<id>.log`. Драйвер не извлекает доказательства из слова `PASS`: успех означает код завершения 0 всех выбранных проверяющих программ. Математические области применения и ограничения приведены в соответствующих `PROOF.md` и независимых отзывах.

Проверяющие программы повторно записывают свои производные JSON-сертификаты и некоторые текстовые раскрытия. Поэтому распакованная папка должна быть доступна для записи. Исходные доказательства и код при проверке не редактируются. Повторный запуск заменяет `aggregate_checks.json` и соответствующие журналы; при необходимости сохраните предыдущий протокол отдельно.

Не запускаются автоматически:

- `embedding_lnd/jet_slice_search.py` — поиск и решение струевых систем;
- `h378/search_constant_mixed_projection.py` — исходный ограниченный поисковый перебор.

Их результаты проверяются перечисленными конечными сертификатами и независимыми аудитами. Для полного воспроизведения итоговых проверок сетевой доступ после установки зависимостей не требуется.

Ни количество пройденных проверок, ни минимальные степени срезов не означают доказательства выпрямляемости новых гармонических моделей, полиномиальности всех ядер или решения общей проблемы вложения.
