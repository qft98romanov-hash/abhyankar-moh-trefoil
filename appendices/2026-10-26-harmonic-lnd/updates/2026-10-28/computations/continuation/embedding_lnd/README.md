# Продолжение: конечные струи и минимальные степени LND-срезов

Дата: 26 октября 2026. Рабочие результаты для независимой проверки.

`PROOF.md` содержит общую теорему о струевой редукции, формулу при большой кратности t^μ, элементарное доказательство описания ядра, 8 точных минимумов при μ=1, полную зависимость от μ для H(3,7,8), а также бесконечное семейство верхних границ.

## Независимая проверка

Из любой папки:

```
python path/to/verify_jet_certificates.py
```

Требуется только стандартная библиотека Python 3. Скрипт проверяет все 14 сертификатов и завершается строкой `ALL 14 EXACT CERTIFICATES PASSED`. Он не требует сетевого доступа, SymPy, решателя линейных систем или формул выпрямления из репозитория.

Нижние сертификаты используют конечную линейную систему из §3 `PROOF.md`. Их полнота для ВСЕХ полиномиальных срезов следует из доказанной весовой редукции §2, а не из ограничения анзаца.

`verified_results.json` содержит все точные коэффициенты верхних срезов и сводку проверенных минимумов. `verification.log` — журнал запуска. Файлы `jet_*_d*.json` включают как итоговые сертификаты, так и дополнительные пробные положительные степени; статус каждого файла указан внутри (`feasible` / `infeasible`).

## Воспроизведение поиска

Требуется SymPy (можно использовать уже имеющийся `research/python_deps`). Пример:

```
python jet_slice_search.py 3 7 8 12
python jet_slice_search.py 3 7 8 22 6
```

Аргументы: a b c d [μ]. Проверяется существование среза степени ≤d для Dμ=t^μ∂u+Cₐ′(u)∂x+C_b′(u)∂y+C_c′(u)∂z. μ по умолчанию равно 1. Проверка конечного результата независима от поиска.

## Границы

Новые минимумы срезов не доказывают выпрямляемость новых гармонических моделей и не доказывают полиномиальность ядер. Степень среза измеряется в заданных исходных координатах. Литературная новизна формулировок не заявляется.
