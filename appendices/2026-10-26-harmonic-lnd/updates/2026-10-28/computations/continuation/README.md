**Дата: 26 октября 2026 года. Статус: рабочее дополнительное приложение, на стадии проверки.**

Это самостоятельный пакет продолжения исследования [abhyankar-moh-trefoil](https://github.com/qft98romanov-hash/abhyankar-moh-trefoil). Его исходная точка — коммит `b954f3609e900761fddc9c8ff03d8301e9604cab`. Предыдущие материалы репозитория не заменяются и не изменяются. Данный пакет сам по себе не опубликован в репозитории.

## Главные результаты

- Полный критерий минимальной обычной степени среза LND вложения через конечную систему условий на производные полинома параметра.
- Восемь точных минимумов при μ=1. Для H(3,7,8) и H(4,5,7) — полная зависимость от μ.
- Совместимая полиномиальность ядра modulo t^N для любого вложения и всех N.
- Для H(3,3n+1,3n+2) — два запрещённых класса параметрических координат без ограничений степени и препятствие естественному переносу.
- Для H(4,5,7) — отсутствие параметрической координаты степени ≤4 с сохранением какой-либо одной из исходных координат.
- Полные ядра и идеалы D^n(ker D^(n+1)) для класса одношаговых переносов, включая кратные исключительные делители.
- Фильтрация и ассоциированное градуированное кольцо последовательных квадратичных модификаций; нетриангулируемость примеров длины ≥2.
- Исправление прежнего направления: относительный ML по всем LND, сохраняющим идеал кривой, всегда тривиален.

## Границы

Нового полного выпрямителя H(3,7,8) или H(4,5,7) здесь нет. Не доказаны ни общая классификация всех H(a,b,c), ни общая нижняя граница 6n+1, ни c((βθ)^3)=3, ни общая проблема сокращения. Степень среза зависит от исходных координат и не является инвариантом сопряжения. Внутренний аудит не заменяет внешнего рецензирования; литературный приоритет не заявляется.

Мотивы, K-теория и гомологическая алгебра не используются.

## Проверки

См. `README_REPRODUCE.md`. Полный итоговый прогон: **PASS 14/14 программ**; это число программ, а не число теорем. Точные численные результаты и версии окружения находятся в `aggregate_checks.json`, журналы — в `logs/`.

```sh
python run_checks.py --stdlib-only
python run_checks.py
```

Первая команда требует только стандартной библиотеки Python. Для второй нужна SymPy 1.14.0. Не применять Python с флагами `-O` / `-OO`: проверки используют `assert`.

Некоторые верификаторы перезаписывают производные JSON и журналы. Поэтому контрольные суммы архива следует проверять **до** повторного запуска вычислений; изменение производных файлов после запуска само по себе не означает повреждение архива.

`MANIFEST.sha256` удостоверяет целостность поставленных файлов, но не математическую истинность. Код поиска новых сертификатов включён отдельно и не запускается автоматически.
