# Относительные ML и Derksen не различают кривые в аффинном пространстве

Дата: 26 октября 2026 года. Статус: самостоятельный элементарный вывод и точная вычислительная проверка примеров; новизна общего механизма не заявляется.

## Точное утверждение

Пусть `k` — произвольное поле характеристики нуль, `n >= 2`, `A=k[x_1,...,x_n]`, а `I` — собственный идеал с `dim(A/I) <= n-2`. Редуцированность и неприводимость `A/I` не предполагаются. Для каждого целого `r >= 1` положим

\[
\mathcal L_r(A,I)=\{0\ne D\in\operatorname{LND}_k(A):D(A)\subseteq I^r\}.
\]

Тогда

\[
\boxed{\bigcap_{D\in\mathcal L_r(A,I)}\ker D=k},\qquad
\boxed{k\left[\bigcup_{D\in\mathcal L_r(A,I)}\ker D\right]=A}.
\]

В частности, прежнее определение

\[
\mathrm{ML}(A,I)=\bigcap_{\substack{D\in\operatorname{LND}_k(A)\\D(I)\subseteq I}}\ker D
\]

даёт `k` для любого вложения кривой в `A^3`, независимо от выпрямляемости. Соответствующая подалгебра Дерксена, порождённая ядрами ненулевых LND, сохраняющих `I`, всегда равна `A`.

Усиление по `r` означает, что не помогает и требование тождественного действия на любом фиксированном конечном инфинитезимальном утолщении `Spec(A/I^r)`. Здесь для разных `r` разрешены разные дифференцирования. Это не утверждение о едином ненулевом дифференцировании, тождественном на всех утолщениях сразу.

## Доказательство

Для `i=1,...,n` обозначим через `R_i=k[x_1,...,x_{i-1},x_{i+1},...,x_n]` кольцо полиномов без `x_i`. Покажем, что `I cap R_i` содержит ненулевой элемент.

Пусть `P_1,...,P_s` — минимальные простые идеалы над `I`. Каждая область `A/P_j` имеет степень трансцендентности над `k` не выше `n-2`. Поэтому образы `n-1` координат из `R_i` алгебраически зависимы: существует `0 != g_{ij} in P_j cap R_i`. Произведение `g_i=product_j g_{ij}` ненулевое, принадлежит `R_i` и каждому `P_j`; следовательно, `g_i in sqrt(I)`. Выбрав степень `N_i` с `g_i^{N_i} in I`, получаем ненулевой `f_i in I cap R_i`.

Для фиксированного `r >= 1` определим

\[
D_{i,r}=f_i^r\frac{\partial}{\partial x_i}.
\]

Так как `partial_i f_i=0`, для любого `F in A` и `m>=0` имеем

\[
D_{i,r}^{\,m}(F)=f_i^{rm}\frac{\partial^mF}{\partial x_i^m}.
\]

Следовательно, `D_{i,r}` локально нильпотентно, ненулевое и `D_{i,r}(A) subseteq f_i^r A subseteq I^r`. Поскольку `A` — область характеристики нуль,

\[
\ker D_{i,r}=\ker\partial_{x_i}=R_i.
\]

Теперь

\[
k\subseteq\bigcap_{D\in\mathcal L_r(A,I)}\ker D
\subseteq\bigcap_{i=1}^nR_i=k.
\]

Это доказывает утверждение о ML. Для утверждения о Derksen достаточно отметить, что для каждой переменной `x_j` существует индекс `i != j`, и тогда `x_j in R_i=ker D_{i,r}`. Поэтому объединение этих `n` ядер порождает всё `A`.

Наконец, каждый `D` с `D(A) subseteq I^r` сохраняет `I` (так как `I^r subseteq I`). Значит, пересечение по всем LND, сохраняющим `I`, не больше уже вычисленного `k`, а порождённая их ядрами подалгебра не меньше уже полученного `A`. Получены оба следствия. □

## Явные действия и гармонические кривые

Пусть `C_n(t)=2T_n(t/2)` и

\[
\gamma(t)=(C_a(t),C_b(t),C_c(t)),\qquad a,b,c\ge1.
\]

Пусть `I=ker(k[x,y,z] -> k[t])` — идеал замыкания образа этой параметризации. Взаимная простота индексов для следующей конструкции не нужна. Положим

\[
f_x=C_c(y)-C_b(z),\quad
f_y=C_c(x)-C_a(z),\quad
f_z=C_b(x)-C_a(y).
\]

Композиционное тождество `C_m(C_n(t))=C_{mn}(t)` даёт `f_x,f_y,f_z in I`. Это ненулевые полиномы, каждый не зависит от соответствующей переменной. Поэтому для любого `r>=1`

\[
D_x=f_x^r\partial_x,\quad D_y=f_y^r\partial_y,\quad D_z=f_z^r\partial_z
\]

являются явными свидетелями обоих утверждений. Например,

\[
\exp(\lambda D_x)(x,y,z)=(x+\lambda f_x(y,z)^r,y,z)
\]

имеет обратное отображение с `-lambda`. Оно тождественно на `Spec(A/I^r)`. Аналогично действуют `D_y,D_z`.

Все эти действия фиксируют кривую поточечно; они не перемещают её точки вдоль параметра. У них не может быть глобального среза: `D(A) subseteq I` при собственном `I` исключает `D(s)=1`. При этом пересечение их ядер уже равно `k`. Тем самым тривиальность относительного ML не обнаруживает ни движущего кривую действия, ни выпрямителя.

## Поправка исследовательской программы

В прежнем `research/cremona_lnd/results.tex` было предложено изучать `ML(A,I)` как потенциальное препятствие к выпрямлению. Логическая импликация «нетривиальный ML пары препятствовал бы выпрямлению» верна, но при указанном определении её предпосылка невозможна для любой кривой в `A^3`. Поэтому это направление в прежней форме закрывается.

Более узкие данные могут сохранять информацию: LND, которые индуцируют **ненулевое** дифференцирование на `A/I`, наличие глобального среза у такого LND, системы коммутирующих LND с заданными орбитами, совместимость с выбранной проекцией и её исключительным делителем. Достаточность каждого такого условия для выпрямления необходимо устанавливать отдельно; настоящий результат её не утверждает.

## Литературное положение

Механизм умножения LND на элемент его ядра — стандартная *replica*. В точном геометрическом контексте см.:

H. Flenner, S. Kaliman, M. Zaidenberg, **A Gromov–Winkelmann type theorem for flexible varieties**, *J. Eur. Math. Soc.* **18** (2016), 2483–2510, DOI [10.4171/JEMS/646](https://doi.org/10.4171/JEMS/646).

- [Страница издателя](https://ems.press/journals/jems/articles/14189).
- [Официальный полный PDF](https://ems.press/content/serial-article-files/32154?nt=1).
- Введение, с. 2484–2485: аргумент Громова–Винкельмана через линейную проекцию и поле `f partial/partial x_1`, фиксирующее подмногообразие.
- Лемма 2.2, с. 2486: `D(A) subseteq I` эквивалентно тождественности действия на подсхеме; `D(I) subseteq I` — её сохранению.
- §2.5(2), (5), с. 2487: replicas и схема-теоретический поточечный стабилизатор.
- Главная теорема 2.6, с. 2487: для гибкого многообразия и замкнутой, возможно нередуцированной подсхемы коразмерности хотя бы два дополнение гибко относительно подходящего стабилизатора.

Наше доказательство для полиномиального кольца использует только алгебраическую зависимость, радикал идеала и частные производные. Глубокая теорема о гибкости для него не нужна. Результат следует рассматривать как явное стандартное следствие, существенное для корректировки данной программы, без заявления о литературной новизне.

## Вычислительная воспроизводимость

`verify_relative_ml.py` проверяет над точными рациональными числами композиционные тождества для шести троек индексов, принадлежность трёх коэффициентов идеалу кривой посредством подстановки, независимость от соответствующей переменной, обратимость сдвигов и поточечную фиксацию параметризации. Проверяются степени `r=1,2,3`. Результаты записываются в `relative_ml_verification.json`.

Вычисления служат проверкой конкретных формул; общий результат доказан выше и не выводится из конечного списка примеров.
