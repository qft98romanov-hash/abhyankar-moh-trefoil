# LND, нормальные поля Эйлера и гармонические кривые

28 октября 2026 года. **Рабочие результаты на стадии проверки.** Этот каталог является дополнительным исследовательским приложением. Он не заменяет прежние материалы и не содержит заявления о решении проблемы выпрямления кривых H(3,7,8) или H(4,5,7). Приоритет и новизна результатов не заявляются.

## Что получено

Пусть R=k[x,y,z], char(k)=0, γ — рассматриваемая полиномиальная параметризация, I — идеал её образа. Исследуется поле δ с условиями

    δ(x), δ(y), δ(z) ∈ I,
    (δ−Id)(I) ⊂ I²,
    div δ = 2.

Эти линейные условия необходимы для рассматриваемого однородного локально нильпотентного поля E=∂t+δ/t на R[t,I/t], но недостаточны. Локальная нильпотентность E остаётся отдельной задачей.

| Кривая | Минимальная степень коэффициентов δ при всех трёх условиях | Размерность полного аффинного семейства в минимальной степени |
| --- | ---: | ---: |
| H(3,7,8) | 8 | 24 |
| H(4,5,7) | 7 | 19 |

Степени относятся к исходным координатам x,y,z. Это минимумы для указанных линейных условий, а не для выпрямителей или LND. Полные семейства и отрицательные сертификаты даны над Q; их утверждения сохраняются при расширении поля характеристики нуль.

В каждом семействе отдельно рассмотрен один рациональный представитель. Оба представителя **не локально конечны**, что доказано через ограничение на инвариантную ось и неограниченный рост степеней итераций. Соответствующие E не являются LND. Это не классифицирует остальные точки семейств, в том числе комплексные.

Вся аффинная семья соответствующую ось не сохраняет: это нарушают 13 из 24 предъявленных направлений для H(3,7,8) и 11 из 19 для H(4,5,7). Поэтому осевое препятствие выбранных представителей не переносится автоматически на семейства целиком.

Для наивной конструкции δP=Σ(Yi−γi(P))∂Yi доказано общее препятствие: если степени координат γ попарно различны и не меньше двух, то никакой полином параметра P не делает соответствующее E локально нильпотентным. Доказательство не ограничено степенью P или числом вычисленных итераций. Контрольные уже выпрямленные случаи показывают, что неудача этой конструкции не является препятствием к выпрямлению самой кривой.

Мотивные методы, K-теория и гомологическая алгебра здесь не используются.

Основные тексты внутри данного каталога:

## Как воспроизвести проверки

Проверенная среда: **Python 3.12 и SymPy 1.14.0**. Проверки используют точную рациональную арифметику; модульные ранги применяются как доказуемые нижние оценки в сочетании с точными ядрами. Численные приближения не заменяют тождества.

После распаковки архива, из его корня:

```sh
python -m venv .venv
```

В Linux/macOS:

```sh
.venv/bin/python -m pip install -r euler_20261028/requirements.txt
.venv/bin/python euler_20261028/run_checks.py
```

В Windows:

```powershell
.venv\Scripts\python.exe -m pip install -r euler_20261028\requirements.txt
.venv\Scripts\python.exe euler_20261028\run_checks.py
```

Если подходящая среда Python уже установлена, достаточно:

```sh
python -m pip install -r euler_20261028/requirements.txt
python euler_20261028/run_checks.py
```

Запускающий файл определяет расположение всех материалов относительно самого себя. Поэтому можно запускать его из любого текущего каталога, указав правильный путь к `run_checks.py`. Перемещать отдельные проверяющие программы без соседних сертификатов не следует.

## Что выполняет общий запуск

Шесть основных программ и одна дополнительная короткая проверка оси запускаются последовательно, каждая из собственного каталога:

1. `verify_theory.py` — точные контрольные примеры общей теории.
2. `verify_divergence_controls.py` — поля, показывающие недостаточность дивергенции и нормальных условий.
3. `h457/verify_euler_obstruction.py` — наивные поля для H(3,4,5), H(3,5,7), H(4,5,7).
4. `h457/normal_search/verify_normal_family.py` — отрицательный сертификат степени ≤6, полнота семейства размерности 19 и препятствие для выбранного представителя.
5. `h378/verify_naive_euler.py` — наивные поля для H(3,7,8) и параметризованного контрольного семейства.
6. `h378/normal_search/verify_normal_certificates.py` — сертификаты степеней 3–8 и отдельные нормальные условия степени 7 без требования дивергенции.
7. `h378/normal_search/verify_degree8_axis_obstruction.py` — препятствие локальной конечности выбранного представителя степени 8.

Запуск может занять несколько минут. Долгие поисковые программы не запускаются: проверяются уже предъявленные сертификаты. Программы поиска сохранены отдельно для воспроизведения способа их получения.

Список без вычислений:

```sh
python euler_20261028/run_checks.py --list
```

Отдельная проверка:

```sh
python euler_20261028/run_checks.py --only h457_normal_family
```

## Протоколы и границы результата

Общий запуск создаёт либо обновляет внутри `euler_20261028/`:

- `aggregate_checks.log` — общий текстовый протокол.
- `aggregate_checks.json` — отдельный статус и время каждой программы, версии среды и общий итог.
- `check_logs/` — индивидуальные протоколы.
- выходные JSON соответствующих проверяющих программ.

`PASS` означает успешное завершение предъявленных точных проверок. При ошибке одной программы последующие всё равно запускаются, а общий код завершения равен 1. Частичный запуск через `--only` проверяет только выбранные программы; это явно отражается в JSON. Прерванные и не запущенные проверки получают отдельные статусы. Утверждения вида «для всех P» или «для всех итераций» требуют также чтения письменных доказательств; конечный набор контрольных вычислений не заменяет их.

Семейства размерности 24 и 19 ещё нужно исследовать на локальную конечность и требуемые спектральные свойства. Данный пакет не утверждает существования подходящего LND в этих семействах и не доказывает невозможности комплексного выпрямления кривых.
