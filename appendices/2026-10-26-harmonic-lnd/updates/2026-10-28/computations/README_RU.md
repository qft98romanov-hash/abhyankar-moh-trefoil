# Полный пакет вычислений

**28 октября 2026 года. Исследовательское приложение на стадии проверки.**

Здесь собраны исходные сертификаты репозитория, опубликованный аппендикс,
продолжение от 26 октября и новые расчёты нормальных полей от 28 октября.
Программы и зависимости исходного репозитория уже находятся внутри пакета:
скачивать их с GitHub для проверки не требуется.

Используйте Python 3.12 и SymPy 1.14.0. Из этого каталога:

```sh
python -m pip install -r requirements.txt
python run_all_checks.py
```

Не используйте ключи `-O` и `-OO`: часть математических проверок использует
`assert`. Общий запуск запрещает этот режим и включает проверки в дочерних
процессах.

По умолчанию запускаются **35 проверяющих программ**, включая все четырнадцать
проверок продолжения и все семь проверок нормальных полей. Это занимает
несколько минут. Долгие поиски новых кандидатов не запускаются. Число программ
не равно числу теорем: часть проверок намеренно перекрывается.

```sh
python run_all_checks.py --list
python run_all_checks.py --only euler_h457_family
python run_all_checks.py --full
```

Последняя команда дополнительно воспроизводит три ограниченных поиска в
отдельных копиях, сохраняя поставленные сертификаты. Остальные исследовательские
поисковые программы также включены; их границы описаны в английских комментариях.

Свежие результаты записываются в `verification_summary.json` и
`verification_logs/`. Старые журналы внутри отдельных каталогов являются
историческими записями. Оригинальные 292 входных файла сохранены без изменений
в `provenance/original_bundle_inputs.zip`.

Во все исполняемые копии добавлены английские комментарии. Для 56 Python-файлов
проверено совпадение AST после удаления строк документации; ещё семь файлов
GAP/Macaulay2 отличаются лишь английским префиксом-комментарием. Проверить это
самостоятельно можно командой:

```sh
python verify_comment_only_edits.py
```

Старый `legacy_appendix/bootstrap_source.py` сохранён как часть истории.
Запускать его в новом пакете не нужно: его манифест описывает оригинальные
байты до добавления комментариев, а все зависимости уже поставлены локально.
Новый реестр исходников находится в `provenance/source_mapping.json`.

GAP и Macaulay2 здесь не были установлены, поэтому сохранены их программы и
исторические журналы исходного репозитория, но новый запуск этих интерпретаторов
не заявляется. Подробная английская инструкция: `README_EN.md`.

Математические доказательства необходимо читать вместе с сертификатами.
Конечные вычисления сами по себе не доказывают утверждений «для всех параметров»
или «для всех итераций». Семейства размерностей 24 и 19 проходят необходимые
линейные условия; их локальная конечность ещё не установлена. Новых выпрямителей
H(3,7,8) и H(4,5,7) в пакете нет. Внешнее независимое рецензирование и
литературный приоритет не заявляются.
