# Standalone Overleaf source check

Date: 28 October 2026.

The source ZIP was extracted into a fresh directory outside the repository.
Its `main.tex` compiled successfully with two XeLaTeX passes, using only the
included sources/fonts and the installed TeX distribution. No overfull boxes,
missing glyphs or undefined references/citations were reported. This verifies
the standalone source package locally; it is not a claim of a browser session
or a project upload to the Overleaf service.
